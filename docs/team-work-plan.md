# Suggested group work plan

Agree on responsibilities with the real team and update this document.

| Workstream | Tasks |
|---|---|
| OOP model | `User`, `Student`, `FoodItem`, `Order`, custom exception |
| Persistence | SQLite schema and repository implementation |
| API/service | Validation, calculations, Javalin routes |
| Front end | Menu, student registration, ordering, vendor status panel |
| Testing/docs | Unit tests, run-through, screenshots, proposal and interview prep |

All group members should understand the full workflow and be able to explain the classes, API, persistence, and validation.
